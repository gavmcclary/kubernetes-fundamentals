Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

**Create a new deployment**
```
oc create deployment demo-deploy --image=nginx
```

**Check all deployments**
```
oc get deployments
```

**Notice how the deployment shows 1/1 Pods Ready**
```
NAME             READY   UP-TO-DATE   AVAILABLE   AGE
demo-deploy      1/1     1            1           ?
```

**Let's scale this deployment from 1 Pod to 3 Pods**
```
oc scale deployment demo-deploy --replicas 3
```

**Notice how number of Ready Pods increases to 3**
```
NAME             READY   UP-TO-DATE   AVAILABLE   AGE
demo-deploy      3/3     3            3           ?
```

**Now look what happens if you check the running Pods**
```
oc get pods
```
```
NAME                           READY   STATUS    RESTARTS      AGE
demo-deploy-6b9484c977-7lszg   1/1     Running   0             ?
demo-deploy-6b9484c977-m2tqg   1/1     Running   0             ?
demo-deploy-6b9484c977-rr5k4   1/1     Running   0             ?
```

**There are now 3 pods for the *demo-deploy* Deployment**

Each Pod has it's unique appendix so that all Pods have a unique name

**Look what happens if you try and delete all pods**
```
oc delete pods --all
```

**Wait a little while for Pods to be deleted...**
```
oc get pods
```
```
NAME                           READY   STATUS    RESTARTS   AGE
demo-deploy-6b9484c977-cmblt   1/1     Running   0          New Age
demo-deploy-6b9484c977-fd9h7   1/1     Running   0          New Age
demo-deploy-6b9484c977-j2444   1/1     Running   0          New Age
```

**Replacement Pods have been created!**

**What about a Deployment manifest**
```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    app: nginx
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
```

**Apply this Deployment and then list the Pods**

**To add the label names to output add the -L option**
```
oc get pods -L app
```
