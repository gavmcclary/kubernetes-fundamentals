Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

**Apply the manifest**

```
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
  labels:
    app: nginx
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:1.14.2
        ports:
        - containerPort: 80
```

**Check deployments**
```
oc get deployments
```
```
NAME               READY   UP-TO-DATE   AVAILABLE   AGE
nginx-deployment   3/3     3            3           ?
```

**Now check ReplicaSets**
```
oc get replicaset
```
```
NAME                          DESIRED   CURRENT   READY   AGE
nginx-deployment-54fd4d6d4c   3         3         3       ?
```

**Notice how a string of random characters is attached to the deployment name - this is the ReplicaSet**

**The Deployment creates the ReplicaSet and the ReplicaSet creates the Pods**
