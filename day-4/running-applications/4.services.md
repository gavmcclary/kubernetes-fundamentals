Instructions
============

A Kubernetes Service provides a stable network endpoint for accessing a group of Pods.

Pods are temporary. They can be deleted, recreated, moved to different nodes and assigned new IP addresses. 

A Service provides a consistent way to communicate with them without needing to know their individual IP addresses.


**Make sure you have started Minikube**
```
minikube start
```

**Create a new nginx deployment**

```
oc create deploy demo-deploy --image=nginx --port=80 --replicas=3
```

**Check the Pods created**
```
oc get pods -o wide
```

**Notice how each Pod has a unique IP address**
```
NAME                           READY   STATUS    RESTARTS   AGE     IP            NODE       NOMINATED NODE   READINESS GATES
demo-deploy-5546f9646d-mhjnf   1/1     Running   0          4m24s   10.244.0.28   minikube   <none>           <none>
demo-deploy-5546f9646d-w6vmn   1/1     Running   0          4m24s   10.244.0.29   minikube   <none>           <none>
demo-deploy-5546f9646d-z98fg   1/1     Running   0          4m24s   10.244.0.27   minikube   <none>           <none>
```

**Make note of the IP address for this first Pod in the output - (yours will be different)**
```
10.244.0.28
```

**Also make note of the Pod name**
```
demo-deploy-5546f9646d-mhjnf
```

**Now delete that Pod**
```
oc delete pod demo-deploy-5546f9646d-mhjnf
```

**And check the Pods again**

```
NAME                           READY   STATUS    RESTARTS   AGE     IP            NODE       NOMINATED NODE   READINESS GATES
demo-deploy-5546f9646d-46mvl   1/1     Running   0          25s     10.244.0.30   minikube   <none>           <none>
demo-deploy-5546f9646d-w6vmn   1/1     Running   0          7m57s   10.244.0.29   minikube   <none>           <none>
demo-deploy-5546f9646d-z98fg   1/1     Running   0          7m57s   10.244.0.27   minikube   <none>           <none>
```

**The two unaffected Pods have stayed the same with the same IP address but the deleted Pod has been recreated with a new IP**

**Note: A Pod can also be placed on a different Node but we only have one node (minikube) on our cluster so this won't happen for us**

## Creating a Service

**To create a Service we need to expose a Deployment**

```
 oc expose deployment demo-deploy
```

This will create a new Service you can check for 

```
oc get service
```

```
NAME           TYPE        CLUSTER-IP       EXTERNAL-IP   PORT(S)   AGE
demo-deploy    ClusterIP   10.97.238.112    <none>        80/TCP    ?
kubernetes     ClusterIP   10.96.0.1        <none>        443/TCP   ?
```

Notice how you already had a Service running called **kubernetes** this is the service that gives access to the API (oc commands) and is created automatically
