Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

The following manifest creates a **PersistentVolume**, a **PersistentVolumeClaim** and a **Pod**.

Note: You can seperate different objects in a manifest by using: **---**
```
apiVersion: v1
kind: PersistentVolume
metadata:
  name: sre-pv
spec:
  storageClassName: manual
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteOnce # Only one node can write at any time 
  hostPath:
    path: "/mnt/data" # where on the node the data is stored
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: nginx-pvc
spec:
  storageClassName: manual
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 1Gi
---
apiVersion: v1
kind: Pod
metadata:
  name: nginx-with-pv
spec:
  nodeSelector:
    kubernetes.io/hostname: minikube
  containers:
  - name: nginx-with-pv
    image: nginx:1.18.0
    ports:
    - name: http
      containerPort: 80
      protocol: TCP
    volumeMounts:
    - name: nginx-pv-storage
      mountPath: "/data"
  volumes:
  - name: nginx-pv-storage
    persistentVolumeClaim:
      claimName: nginx-pvc
```

Once you have applied this manifest check the resources have been created:
```
oc get pv
```
```
NAME     CAPACITY   ACCESS MODES   RECLAIM POLICY   STATUS   CLAIM               STORAGECLASS   VOLUMEATTRIBUTESCLASS   REASON   AGE
sre-pv   1Gi        RWO            Retain           Bound    default/nginx-pvc   manual         <unset>                          ?
```
```
oc get pvc
```
```
NAME        STATUS   VOLUME   CAPACITY   ACCESS MODES   STORAGECLASS   VOLUMEATTRIBUTESCLASS   AGE
nginx-pvc   Bound    sre-pv   1Gi        RWO            manual         <unset>                 ?
```

Now exec into the Pod:
```
oc exec -it nginx-with-pv -- sh
```
There should be a **/data** directoy (this was created from the above manifest - under **volumeMounts**
```
ls
```
```
bin  boot  **data**  dev  docker-entrypoint.d  docker-entrypoint.sh  etc  home  lib  media	mnt  opt  proc	root  run  sbin  srv  sys  tmp	usr  var
```
