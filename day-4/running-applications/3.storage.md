Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

```
apiVersion: v1
kind: PersistentVolume
metadata:
  name: sre-pv
spec:
  storageClassName: manual
  capacity:
    storage: 1Gi
  accessModes:
    - ReadWriteOnce # Only one node can write at any time 
  hostPath:
    path: "/mnt/data" # where on the node the data is stored
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: nginx-pvc
spec:
  storageClassName: manual
  accessModes:
    - ReadWriteOnce
  resources:
    requests:
      storage: 1Gi
---
apiVersion: v1
kind: Pod
metadata:
  name: nginx-with-pv
spec:
  nodeSelector:
    kubernetes.io/hostname: node-1
  containers:
  - name: nginx-with-pv
    image: nginx:1.18.0
    ports:
    - name: http
      containerPort: 80
      protocol: TCP
    volumeMounts:
    - name: nginx-pv-storage
      mountPath: "/data"
  volumes:
  - name: nginx-pv-storage
    persistentVolumeClaim:
      claimName: nginx-pv 
```
