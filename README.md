# kubernetes-fundamentals
**Schedule**

| Day   | Theme                       | Topics                                                         | Practical                                                  |
| ------| --------------------------- | -------------------------------------------------------------- | ---------------------------------------------------------- |
| **1** | Getting started             | Minikube installation, Basic Linux, Namespaces, Pods           | Linux investigation and Create and inspect your first Pod  |
| **2** | Kubernetes objects          | Making Pods, Manifests, Logs, Resource Monitoring              | Build a Pod from YAML and troubleshoot it                  |
| **3** | Application configuration   | ConfigMaps, Secrets, Volume Mounting                           | Deploy an application using external configuration         |
| **4** | Running applications        | Deployments, Storage, StatefulSets                             | Convert a Pod into a Deployment and add persistent storage |
| **5** | Troubleshooting & challenge | Review + Challenges                                            | Diagnose deliberately broken workloads                     |

**About the sessions**

Each session is expected to last 1-2hrs 

Learners will need laptops

Each session includes some practical tasks/practice with OpenShift commands and/or Unix/Linux commands

Session 5 consists of a series of challenges to check understanding of everything covered by first 4 sessions

Each Session/Day has a corresponding folder in the repo and in that folder files are numbered e.g.

```
1. minikube-installation.md

2. useful-unix-commands.md

3. instructions.md
```

Start at file number 1 and go from there 

Learners do not have to clone the repo, they can just copy and paste contents of files if they want
