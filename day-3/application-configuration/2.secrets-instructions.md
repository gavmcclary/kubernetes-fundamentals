Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

Create a new secret from the manifest:
```
my-secret.yaml
```

**List all secrets**
```
oc get secrets
```

**Describe the secret**
```
oc describe secret my-secret
```

**Let's create a Pod that uses this secret**
```
apiVersion: v1
kind: Pod
metadata:
    name: mysql-locked
spec:
  containers:
  - image: mysql:8.0
    name: mysql
    env:
      - name: MYSQL_ROOT_PASSWORD
        valueFrom:
          secretKeyRef:
            name: my-secret
            key: password
```

**Wait for Pod to spin up**

**Then exec into it**
```
oc exec -it mysql-locked -- bash
```

**See if you can view the password**
```
echo $MYSQL_ROOT_PASSWORD
```
