Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

**Logs**

We can view container logs with the following command:

```
oc logs <pod-name>
```

Apply the manifest: **counter.yaml**

What is the problem with using the command **oc logs counter**?
```
oc logs counter
```

**View specific container logs:**

```
oc logs counter -c countby3
```

**View all containers:**

```
oc logs pod/counter --all-containers=true --prefix=true
```

**Don't forget to delete the Pod when you're finished**
```
oc delete pod counter
```
