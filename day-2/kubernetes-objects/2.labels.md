Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

**Labels** can be used to tag Pods (amongst other things) so that they are both easier to iedntify and find with in Kubernetes.

Take a basic Pod manifest and apply it to your cluster:

```
apiVersion: v1
kind: Pod
metadata:
  name: demo-pod
spec:
  containers:
  - name: count
    image: nginx
```

Now run the command:
```
oc get pods --show-labels
```

This will add the **LABELS** column to the output:

```
NAME       READY   STATUS    RESTARTS   AGE   LABELS
demo-pod   1/1     Running   0          ?     <none>
```
