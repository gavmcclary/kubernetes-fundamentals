Instructions
============

**Make sure you have started Minikube**
```
minikube start
```

**Labels** can be used to tag Pods (amongst other things) so that they are both easier to identify and find with in Kubernetes.

Take a basic Pod manifest and apply it to your cluster:

```
apiVersion: v1
kind: Pod
metadata:
  name: demo-pod
spec:
  containers:
  - name: count
    image: nginx
```

Now run the command:
```
oc get pods --show-labels
```

This will add the **LABELS** column to the output:

```
NAME       READY   STATUS    RESTARTS   AGE   LABELS
demo-pod   1/1     Running   0          ?     <none>
```

To make it easier to see what happens when labels are added and removed run this command:
```
oc get pods -w --show-labels
```

Now open another terminal window
```
Terminal > Shell > New window
```

Open the basic Pod manifest you created earlier and add the following:
```
apiVersion: v1
kind: Pod
metadata:
  name: demo-pod
  labels:
    sre:legends
spec:
  containers:
  - name: count
    image: nginx
```

Then make sure to apply the changes:
```
oc apply -f basic-pod.yaml
```

Now watch as the label is added:
```
NAME       READY   STATUS    RESTARTS   AGE     LABELS
demo-pod   1/1     Running   0          ?       sre=legends
```

You can add more labels:
```
oc label pod demo-pod another=label
```

```
NAME       READY   STATUS    RESTARTS   AGE   LABELS
demo-pod   1/1     Running   0          ?     another=label,sre=legends
```

Remove a label:
```
oc label pod demo-pod another-
```

```
NAME       READY   STATUS    RESTARTS   AGE   LABELS
demo-pod   1/1     Running   0          21m   sre=legends
```

To quickly see which Pods have a specific label use this command:
```
oc get pods -L sre
```

```
NAME       READY   STATUS    RESTARTS   AGE   SRE
demo-pod   1/1     Running   0          23m   legends
```

Now if you create another pod without the *sre* label it won't show:
```
oc run another-pod --image=nginx
```

```
 oc get pods -L sre
```
```
NAME          READY   STATUS    RESTARTS   AGE   SRE
another-pod   1/1     Running   0          ?   
demo-pod      1/1     Running   0          ?     legends
```

Finally, let's add another pod:
```
oc run another-pod2 --image=nginx
```

Then label it:
```
oc label pod another-pod2 sre=legends
```

Now if we want to only see pods with labels *sre* we can use the **--selector** option:
```
oc get pods --selector=sre=legends
```

```
NAME           READY   STATUS    RESTARTS   AGE
another-pod2   1/1     Running   0          ?
demo-pod       1/1     Running   0          ?
```
