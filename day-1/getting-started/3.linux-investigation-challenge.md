Linux Investigation Challenge
=============================

You have been asked to investigate an application running on a Linux server.

All files are contained in the folder: **challenge**

Without opening every file manually, answer the following:

1. What files and directories are present?
2. Find all YAML files.
3. What application is being run?
4. What port is the application configured to use?
5. What is the application version?
6. How many ERROR entries are in the application log?
   
   **TIP:** To get a count of lines use the ```wc``` command - use in conjunction with ```man``` to figure out how to get a count of lines.
8. Save all ERROR entries from application.log into a new file called errors-found.txt.
9. Display the last 5 lines of application.log.
