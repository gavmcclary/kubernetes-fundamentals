Useful Commands
===============

**Searching**

Command:
```
grep
```

Search for the word **ERROR** in a log file
```
grep ERROR application.log
```


Search for the word **ERROR** in a log file and return line number
```
grep -n ERROR application.log
```

Command:
```
find
```

Find any files with **.log** extension

```
find . -name "*.log"
```

**Combining commands**

Command:
```
|
```

List all files and pipe to grep to search for **yaml**

```
ls -la | grep yaml
```

**Redirection**

Output to a file 

```
ls -l > output.txt
```

Append

```
ls -l >> output.txt
```

Combine with pipe

```
cat output.txt | grep yaml
```

**Logs**

Use **tail** to look at end of logs - provide a number to only show the last n lines
```
tail -1 application.log
```
